How to name a location!
  1. Place a sign where you want the location.
  2. On the first line, write [dynmap].
  3. On the next lines, write the name, like Wheat farm.
  4. Click Done. The location shows up here and on the map within a minute or two.

For now, only server operators can place these signs.
