Your server address

https://streaming.xgold.tech

Enter this full address when an app asks you to add a server. Keep https://; there’s no port number to add.

Open Jellyfin in browser

On a computer or browser

  1. Open Jellyfin.
  2. Sign in with the Jellyfin username and password Carter gives you.
  3. Choose a library, or open Live TV to watch the shared stream.

On a phone, tablet, or TV

  1. Install a compatible app from the Jellyfin apps list.
  2. Choose Add Server or Connect to Server and enter https://streaming.xgold.tech.
  3. Sign in with your Jellyfin username and password.

Join the watch party

In Jellyfin, open Live TV → On Now or Channels, then select Discord Watch Party (channel 900).

Someone needs to start the source in Discord first. If the source changes, stop and reopen the Jellyfin channel. Jellyfin and Discord can have different playback delays.

Need a hand?

I don’t have a login.

Ask Carter to create a Jellyfin account or reset your password. Use the credentials supplied for Jellyfin.

The app can’t find the server.

Automatic discovery works only on the home network. Away from home, choose Add Server and enter https://streaming.xgold.tech manually. A home address beginning with 192.168. won’t work from outside.

The website won’t open.

Check the server address, then try opening it in your browser. On a phone, try cellular data with Wi-Fi off. If it still won’t load, let Carter know so he can check the server and remote connection.

The watch-party card is there, but it won’t play.

The card is a channel listing and can appear while no stream is running. Ask the host to start playback in Discord, then reopen the channel.

Playback buffers.

Try a stronger Wi-Fi connection or a lower playback quality in the app. If the problem persists, tell Carter which device and app you’re using.
